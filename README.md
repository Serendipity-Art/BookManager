BookManager 图书管理系统
一个普通大二学生的第一个 Java 项目，还在慢慢学习和完善中。
关于这个项目
大家好，我是 Serendipity-Art，目前是一名大二在读学生。
BookManager 是我学习 Java 后端开发以来，第一次尝试独立完成的完整项目。说实话，在开始写这个项目之前，我连 Maven 的 pom.xml 都看不太懂，更别说把项目部署到服务器上了。整个过程磕磕绊绊，遇到报错就查资料、问同学、翻文档，就这样一点一点把功能搭了起来。
这个项目远谈不上完美，代码写得也不算优雅，很多地方可能还显得比较“学生气”。但我还是决定把它开源出来，一方面是想记录自己的学习历程，另一方面也希望能得到各位前辈和同学的指点——哪怕只是一句“这里可以写得更好”，对我来说都是莫大的帮助。
